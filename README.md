# Signal Simulator

An interactive web-based simulator for generating, visualizing, and exploring signals and systems concepts.

The **Signal Simulator** is designed as an educational tool for ECE students to understand signal behavior through interactive visualization instead of relying only on theoretical plots.

## Features

* 📈 Generate and visualize different types of signals
* 🔄 Interactive signal parameter adjustment
* 📊 Visual representation of signal waveforms
* ⚡ Explore signal properties and behavior
* 🎛️ Modify signal parameters and observe changes
* 💻 Responsive and user-friendly interface
* 🚀 Runs directly in a web browser

## Technologies Used

* **React.js** — Frontend development
* **JavaScript** — Application logic
* **Tailwind CSS** — User interface styling
* **HTML & CSS** — Web structure and styling
* **Node.js / npm** — Package management and development

## Getting Started

### Prerequisites

Make sure you have **Node.js and npm** installed on your system.

### Installation

Clone the repository:

```bash
git clone https://github.com/vishaal-hariharan/Signal-Simulator.git
```

Navigate to the project directory:

```bash
cd Signal-Simulator
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will open at:

```text
http://localhost:3000
```

## Project Purpose

This project was developed to provide an interactive way to study and visualize concepts from **Signals and Systems**.

Instead of manually drawing waveforms, users can interact with the simulator and observe how changes in signal parameters affect the resulting waveform.
